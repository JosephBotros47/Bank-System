# Bank Management System

A simple Bank Management system built with C# using Object-Oriented Programming (OOP) concepts.

## 🌟 Features

### For Managers
- Login with name and age
- Add new Clients  (A)
- Remove Client from Bank  (R)
- Display all Client bank have    (D)
- For exit from manager mode

### For Users
- Login with name and age
- Deposit operation  (D)
- Withdraw operation    (W)
- Transfer operation  (T)
- Display user card with his information (S)
- For exit from manager mode

## 🛠 Technologies Used

- **Programming Language**: C#
- **Application Type**: Console Application
- **Paradigm**: Object-Oriented Programming (Inheritance, Encapsulation, Polymorphism)
- **Framework**: .NET

## 🚀 How to Run

### Prerequisites
- [Visual Studio](https://visualstudio.microsoft.com/) or [Visual Studio Code](https://code.visualstudio.com/)
- .NET SDK
